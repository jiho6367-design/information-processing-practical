03 / VISUAL TRACE

값이 바뀌는 과정 직접 보기

다음 단계 버튼을 누르면 값과 방문 위치가 바뀝니다.

C · 값 복사와 주소 전달

&i는 i의 위치를, i는 숫자만 넘깁니다.

0/3 · i = 30, 배열은 [2,4,6,8,10].

C · 세 번째로 읽은 노드 값 찾기

자식부터 방문합니다. 세 번째로 읽은 값만 저장합니다.

0/5 · 아직 읽은 노드가 없습니다.

입력이 1 이하이면 그 값으로 끝내기

Java 예제 · compute(5)
static int compute(int num) {
    if (num <= 1) return num;
    return compute(num - 3) + compute(num - 1);
}
입력코드대로 계산돌려주는 값
-11 이하이므로 -1로 끝남-1
01 이하이므로 0으로 끝남0
11 이하이므로 1로 끝남1
2compute(-1)+compute(1) = -1+10
3compute(0)+compute(2) = 0+00
4compute(1)+compute(3) = 1+01
5compute(2)+compute(4) = 0+11

앞에서 구한 반환값을 다시 씁니다. 이 함수에는 다른 값을 바꾸는 줄이 없습니다.
