Java 재귀 · 음수 기저값을 놓치지 않기

2026년 2회 19번은 num ≤ 1이면 그 숫자를 그대로 반환합니다. f(-1)도 호출됩니다. 피보나치처럼 모든 종료값을 0이나 1로 바꿔 생각하면 오답입니다.

원문 재귀식의 핵심
static int compute(int num) {
    if (num <= 1) return num;
    return compute(num - 3) + compute(num - 1);
}
// 구할 값: compute(5)
f(-1)=-1, f(0)=0, f(1)=1
f(2)=f(-1)+f(1)=0
f(3)=f(0)+f(2)=0
f(4)=f(1)+f(3)=1
f(5)=f(2)+f(4)=1

빠른 풀이: 이 함수는 외부 상태를 바꾸지 않습니다. 작은 입력의 반환값을 표에 저장해 재사용하세요. 출력은 1이며 Java로 직접 실행해 확인했습니다. 전역·static을 바꾸는 재귀에는 같은 생략법을 그대로 적용하지 않습니다.
