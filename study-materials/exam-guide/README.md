# 정처기 실기 · 기출에서 개념으로

`index.html`을 브라우저에서 직접 열면 됩니다. 별도 설치나 서버가 필요 없습니다. 원문 링크를 함께 쓰려면 저장소의 `pdf/` 폴더를 유지하세요. GitHub는 HTML을 소스로 표시하므로 로컬에서 열거나 HTML 파일을 내려받아 읽습니다.

`predictions.html`은 2026년 실기 3회 대비 예상 연습입니다. 코딩·SQL 20문항(C 8, Java 6, Python 4, SQL 2)과 약점 보완용 네트워크 계산 8문항을 직접 만들었습니다. 정답·풀이 접기, 내 답안 저장·표기 비교, 계산 도식과 서브넷 검산 도구를 제공합니다. 실제 미래 시험을 안다는 의미의 예상이 아니며, 관측된 요구 능력에 근거한 변형 연습입니다. 문항마다 유형 선정 근거를 표시했습니다.

## 범위와 작성 방법

- 2020~2026년 업로드 PDF 21개를 대상으로 문제를 독립 분석했습니다.
- 2020년 4·5회 합본은 한 파일·한 문항 묶음입니다. 2024년 1회 19·20번은 미복원이라 제외합니다. 총 418문항: 코딩 138, SQL 36, 이론 244.
- PDF 해설을 사용해 설명을 작성하지 않았습니다. 사용자 지시 이전 초기 확인에서 노출된 2020년 1회 해설 일부도 분석에 사용하지 않았습니다. 재생성 스크립트는 답·해설 제목을 만나면 중단하고 문제 페이지만 저장합니다.
- 코딩 문법·API 문제는 코딩, SQL 작성·실행 결과는 SQL, 정의·비교·운영체제·네트워크 계산은 이론으로 한 번씩 집계합니다. 코딩의 대표 유형은 다중 기술 중 주된 요구 능력입니다.
- 2026년 2회의 텍스트는 정확하다는 사용자 설명을 전제로 풀이했습니다. 누락된 그림·업무 규칙은 가정을 명시하고 조건부로 추론했습니다. 가정 아래 답과 확정 계산을 구별합니다.
- 코드 예제는 자체 작성하거나 최근 원문의 핵심 동작을 재작성했습니다. C, Java, Python, SQLite로 실행 결과를 확인합니다. C 평가 순서처럼 표준상 정해지지 않는 결과는 단일 컴파일러 결과로 일반화하지 않습니다.
- 본문 출처 번호의 페이지는 PDF 파일 페이지이며 책의 인쇄 페이지가 아닙니다.

## 사용

개념 검색·언어 필터 → 원하는 개념 펼치기 → 코드와 표를 손으로 추적 → 실행 결과·셀프 체크 확인 → 복습 체크 순서로 사용하세요. 실행 표의 `한 단계씩 보기`는 검증한 표를 단계적으로 보여주며 C·Java 코드를 브라우저에서 실행하지는 않습니다. 포인터·후위 순회 도식에는 별도 단계 버튼이 있습니다.

복습 체크는 `localStorage`에 저장합니다. 저장이 차단된 브라우저에서도 읽기는 가능합니다. 인쇄 버튼은 모든 개념을 펼친 뒤 인쇄 대화상자를 열고 완료 후 기존 보기로 복원합니다.

## 재생성

Python에 PyMuPDF가 필요하며 실행 검증에는 GCC, JDK가 필요합니다. Python의 SQLite는 RIGHT JOIN 지원 버전을 사용하세요.

```powershell
python scripts/extract_study_sources.py
python scripts/build_exam_guide.py
python scripts/verify_exam_guide.py
python scripts/build_predictions.py
python scripts/verify_predictions.py
```

`data/*-inventory.json`은 문항별 주제 분류와 주의사항, `data/*-lessons.json`은 독립 작성한 개념·예제입니다. `data/analysis.json`에는 파일 해시·집계·전체 문항표, `data/verification.json`에는 예제와 최근 원문 핵심 동작의 실행 검증 결과가 들어 있습니다. 추출 문제·컴파일 결과 등 임시 자료는 Git에서 제외되는 `tmp/`에 저장합니다.

예상문항의 데이터는 `data/predictions.json`, 실행·계산 검증 결과는 `data/prediction-verification.json`입니다. 네트워크는 Python `ipaddress`, 라우팅은 BFS·Dijkstra로 계산값을 별도 확인합니다. FLSM·수용 호스트 수 역산은 관찰된 서브넷 유형을 확장한 연습이라고 표시했습니다.

현재 학습 자료는 업로드한 복원 문제를 대상으로 하며 다음 시험의 출제 확률을 산출한 자료는 아닙니다.
