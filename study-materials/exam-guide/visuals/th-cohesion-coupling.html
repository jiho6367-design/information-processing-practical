응집도 · 결합도

큰 상자의 안을 볼까, 상자 사이를 볼까?

모듈 안의 연결은 응집도, 모듈 사이에 넘기는 것은 결합도입니다.

안: 앞 결과를 다음 작업에 사용

출력 → 다음 입력 = 순차적 응집도

두 작업이 같은 큰 상자 안에 있습니다. 순서뿐 아니라 자료가 이어지는지 보세요.

밖: 다른 모듈에 삭제를 지시

처리 방법을 지시 = 제어 결합도

화살표가 모듈 경계를 넘습니다. 숫자 같은 처리 자료인지, 처리 방법을 정하는 선택값인지 보세요.

비슷한 말은 이 차이만 확인

실제 연결선택할 말보는 곳
정제 결과를 집계의 입력으로 사용순차적 응집도앞 출력 → 뒤 입력
같은 고객 자료로 서로 다른 보고서 작성교환적 응집도같은 자료를 함께 사용
자료 연결 없이 정해진 순서대로 작업절차적 응집도실행 순서만 있음
sum(x, y)에 필요한 숫자만 전달자료 결합도필요값만 전달
고객 레코드 전체 전달스탬프 결합도자료 구조를 통째로 전달

목표: 모듈 안은 한 기능으로 잘 묶고(높은 응집도), 밖에 대한 의존은 줄입니다(낮은 결합도).

결합도내용 → 공통 → 외부 → 제어 → 스탬프 → 자료
