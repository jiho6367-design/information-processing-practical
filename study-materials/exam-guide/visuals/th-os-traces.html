CPU 시간축과 메모리 칸

완료 시각을 먼저 읽고, 대기시간을 계산하세요

CPU는 각 작업의 끝을 찾습니다. LRU는 값이 든 칸과 마지막 사용 순서를 함께 기록합니다.

그림을 좌우로 밀어 전체를 보세요.

작업도착총 실행완료대기 = 완료−도착−실행
A081717−0−8=9
B1455−1−4=0
C292626−2−9=15
D351010−3−5=2

평균 대기시간 = (9+0+15+2)/4 = 6.5. 처음 시작한 시각만으로 대기를 구하면 A의 중간 대기를 놓칩니다.

LRU는 “가장 오래 사용하지 않은 값”을 교체합니다

1 · 11 · 빈 칸 · 빈 칸1fault: 빈 칸에 1

총 6번 참조 = hit 1회 + fault 5회. 빈 칸에 처음 가져올 때도 fault로 셉니다.

그림을 좌우로 밀어 전체를 보세요.

방식바로 보는 기준계산에서 조심할 점
SJF준비된 작업 중 총 실행시간이 가장 짧은 작업실행 도중 새 작업이 와도 중단하지 않음
SRT준비된 작업 중 현재 남은 시간이 가장 짧은 작업더 짧은 작업이 오면 바꿀 수 있음
RR대기줄 순서와 시간 할당량미완료 작업은 뒤로 이동
HRN(대기+실행)/실행값이 큰 작업부터 선택
FIFO메모리에 처음 들어온 순서같은 참조 1·2·3·1·4·2에서는 fault 4회
LFU사용 횟수가 가장 적은 페이지동률 처리·다시 가져올 때 횟수 처리 조건 확인

반환시간은 완료−도착입니다. 실행할 작업이 없으면 시간축에 빈 구간을 남기세요. LRU는 마지막 사용 순서, FIFO는 들어온 순서입니다.

확인: 도착 2, 총 실행 5, 완료 14 → 대기 14−2−5=7.
