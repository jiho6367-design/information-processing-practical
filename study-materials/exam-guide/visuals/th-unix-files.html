권한 4·2·1 격자

켜진 칸의 숫자만 더하세요

r은 읽기 4, w는 쓰기 2, x는 실행 1입니다. 없으면 그 칸은 0입니다.

그림을 좌우로 밀어 전체를 보세요.

640도 같은 격자로 거꾸로 풀어보세요

대상읽기4쓰기2실행1합계 → 문자
소유자4206 → rw-
그룹4004 → r--
기타 사용자0000 → ---

chmod 640 memo.txt → rw- r-- ---. 소유자는 읽기·쓰기, 그룹은 읽기, 기타는 권한 없음.

경로 명령·링크·파일 찾기 방식
정확한 명칭쉬운 뜻구별할 점
pwd / ls / cd현재 경로 출력 / 목록 / 위치 이동현재 위치를 바꾸는 것은 cd
cp / cat / ps복사 / 내용 출력 / 실행 중인 작업 확인파일 복사·파일 내용·프로세스를 구별
심볼릭 링크대상 경로를 가리키는 별도 링크대상 경로가 사라지면 깨진 링크가 될 수 있음
하드 링크같은 파일의 inode를 함께 참조하는 이름경로를 저장하는 심볼릭 링크와 구별
경쟁 조건확인한 뒤 실제 사용할 때까지 대상이 바뀔 수 있음링크가 바뀌면 높은 권한의 작업이 다른 파일을 쓸 수 있음
순차 접근차례대로 찾기앞에서 뒤로 읽음
인덱스 접근값과 주소의 대응표로 찾기<값, 주소> 관계를 이용
해싱 접근키에 함수를 적용해 위치 찾기키 → 함수 → 저장 위치

이 예제는 특별 권한 비트를 제외한 기본 세 자리입니다. 디렉터리의 x는 파일 실행과 달리 경로를 탐색·접근하는 권한에 관련됩니다. 링크 종류의 이름과 확인·사용 사이에 바뀌는 공격 과정을 따로 구별하세요.

확인: 현재 작업 경로를 출력하는 명령은 pwd입니다. 이동은 cd, 목록은 ls입니다.
