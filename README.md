# 정보처리기사 실기 연습실

## 포트폴리오 개요

- **형태**: 정보처리기사 **실기** 시험을 준비하기 위해 만든 개인 학습용 웹 앱입니다.
- **주요 기능**: 연습·시험 모드, 답안 작성과 채점·해설 비교, 학습 기록 저장, 기출 분석·개념 교재와 계산 연습.
- **본인 역할**: 학습에 필요한 기능과 화면 개선 사항을 AI에 전달하고, 코드 실행·문제풀이 동작을 확인하며 오류와 설명의 개선을 요청했습니다.
- **실행 형태**: 개인 PC의 로컬 서버에서 사용합니다. 이 GitHub URL은 소스 저장소이며 즉시 접속해 문제를 푸는 배포 사이트 주소가 아닙니다.
- **자료 범위**: 기존 문서의 원본 PDF·문제·해설에 관한 개인 학습용 제한을 유지합니다. 코드 구현과 문제 자료의 이용 범위는 구분합니다.
- **검증 안내**: 아래 검사 명령과 QA 보고서가 포함되어 있습니다. README 정리 과정에서 앱 테스트를 새로 실행한 것은 아닙니다.

---

개인 PC에서 정보처리기사 실기 복원 문제를 연습하기 위한 로컬 전용 사이트입니다.

## 실행

```powershell
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5174/`를 엽니다.

## 사용

- 연습 모드에서는 답을 비워 둔 채로도 `채점하고 해설 보기`를 누를 수 있습니다.
- 시험 모드에서는 회차를 제출한 뒤 `문제·해설 비교`에서 정답과 풀이를 확인합니다.
- 입력칸 밖에서는 `←`·`→` 방향키로 답안 작성 여부와 관계없이 이동합니다.
- 데스크톱은 문제와 해설을 좌우로 비교하고, 작은 화면은 문제·해설 탭을 사용합니다.
- 답안·현재 문항·완료 기록은 이 사이트 전용 브라우저 저장소에 자동 저장됩니다.

## 검사

```powershell
npm run refresh-data
npm run validate-data
npm run audit-pdf
npm run verify-executions
npm test
npm run lint
npm run build
```

검사 결과 요약은 `reports/QA_REPORT.md`에서 확인할 수 있습니다.

## 기출 분석·개념 교재

[`study-materials/exam-guide/index.html`](study-materials/exam-guide/index.html)을 브라우저에서 직접 열면 됩니다. 인터넷 연결 없이 읽을 수 있습니다.

- `pdf/`의 2020~2026년 자료 21개에서 분석 가능한 418문항을 분류했습니다.
- 이론, C·Java·Python 코딩, SQL을 나누고 직접 만든 예제·실행 추적표·도식·셀프 체크를 제공합니다.
- 원문 문제 페이지 링크, 문항 검색, 개념 검색, 복습 표시와 인쇄를 지원합니다.
- 분석 방법과 재생성 명령은 [교재 안내](study-materials/exam-guide/README.md)에 있습니다.
- [2026년 3회 대비 예상·계산 연습](study-materials/exam-guide/predictions.html)은 C 8, Java 6, Python 4, SQL 2와 네트워크 계산 8문항을 제공합니다. 정답은 접혀 있으며 출제 경향 추론·실행표·계산 도식·서브넷 검산 도구가 포함됩니다.

원본 PDF와 변환된 문제·해설은 개인 학습 용도로만 사용하고 외부에 공개하지 마세요.

## GitHub 백업 안내

개인 학습용 저장소입니다. 실행에 필요한 코드, 변환된 문제 데이터와 이미지, 기출 분석 교재를 포함합니다. 사용자가 업로드한 원본 기출 PDF는 `pdf/`에 있습니다. 설치 의존성(node_modules), 빌드 결과와 임시 파일은 제외합니다. 학습 기록은 브라우저에 저장되며 이 저장소에 포함되지 않습니다.
