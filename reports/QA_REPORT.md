## PDF 원본 전수 검사

`scripts/audit_pdf_source_coverage.py`로 138문항 전체를 검사했다.

- PDF에서 다시 추출한 문제 본문과 데이터의 원문 본문이 일치함
- PDF에서 다시 추출한 정답과 데이터의 정답이 일치함
- PDF 원문 해설과 `sourceExplanation`이 일치함
- 문제 페이지와 정답·해설 페이지 번호가 일치함
- 공개 폴더의 PDF 사본 SHA-256이 작업 폴더 원본과 일치함
- 138개 원본 페이지 이미지가 모두 정상적으로 열림
- 누락·중복 문항 번호, 빈 답칸, 빈 정답, 빈 편집 해설 없음

상세 결과: `reports/pdf-source-audit.json`

## 해설 검증

- PDF 원문 해설과 초보자용 해설을 별도 필드·별도 파일로 관리함
- 138개 편집 해설의 필수 항목과 PDF 원문 문장 그대로의 재사용 여부를 자동 검사함
- 코드·SQL 68문항 모두 실행 순서와 값 추적표가 있음
- Java 23문항, Python 10문항, SQL 10문항은 실제 실행 결과와 정답을 대조함
- 실행할 수 없는 C 24문항과 Java 실행 순서 1문항은 손 추적 결과와 PDF 정답을 대조함
- 2025년 2회 10번은 C 함수 인수 평가 순서가 언어 표준에서 정해져 있지 않아 `검토 필요`로 표시함

실행 검증 기록: `src/data/execution-verification.json`

## 기능 검사

- 빈 답안도 `채점하고 해설 보기` 가능, 미입력은 오답으로 표시
- 복수 답칸은 모든 칸이 맞아야 문항 정답
- 공백과 영문 대소문자를 무시하는 채점
- 시험 제출 전 정답·해설 비공개
- 시험 제출 뒤 전체 문제·이전 답안·정답·해설 비교
- 답안과 현재 문항 자동 저장 및 새로고침 뒤 복원
- 문항 번호 버튼으로 미답변 문항 이동
- 입력칸 밖 `ArrowLeft`·`ArrowRight` 이동
- 입력칸 안 방향키는 커서 이동으로 유지
- 데스크톱 문제·해설 1:1 좌우 배치와 양쪽 독립 스크롤
- 760px 이하에서 문제·해설 탭과 활성 패널만 표시하는 반응형 규칙
